# 🚀 Task Manager

Сучасний повнофункціональний веб-застосунок для персонального та командного тайм-менеджменту. Поєднує інтерактивний щоденний календар з 30-хвилинним плануванням, гнучку Канбан-дошку з підтримкою зміни порядку колонок та систему ізольованих робочих команд.

**Демо:** [coursework-task-manager.vercel.app](https://coursework-task-manager.vercel.app)


---

## ✨ Основні можливості

### 1. 📅 Інтерактивний Календар (30-хвилинна сітка)
- **Точний погодинний розклад** з кроком у 30 хвилин (`:00` та `:30`).
- **Беклог нерозподілених задач** — зручна бічна панель задач без встановленого часу.
- **Drag & Drop планування** — перетягуйте задачі з беклогу прямо у часові слоти календаря.
- **Гнучка зміна розкладу** — переміщення задач між годинами та днями, пропорційне масштабування висоти картки відповідно до тривалості.
- **Швидке скидання в беклог** — повернення задачі до беклогу перетягуванням.

### 2. 📌 Канбан-дошка нового покоління
- **Drag & Drop задач** між колонками з миттєвим збереженням статусу.
- **Зміна порядку колонок між колонками** — затисніть ручку `⠿` і перетягніть колонку у простір між сусідніми колонками. Синій неоновий індикатор вказує точну точку вставки.
- **Персоналізоване збереження** порядку колонок у профілі користувача.
- **Створення та видалення власних колонок** зі збереженням стандартних етапів.
- **Інформативні картки** з відображенням дати, часу, виконавців та кольорових категорій.

### 3. 👥 Ізольовані Команди (Teams)
- **Створення команд** з автоматичною генерацією унікального 6-значного коду запрошення.
- **Приєднання за кодом** або миттєве додавання колег за їх `email` чи `username`.
- **Повна ізоляція виконавців** — при призначенні завдань у формі відображаються **виключно учасники вашої команди**, що забезпечує приватність та командний фокус.
- Модальне вікно керування складом команди, списком учасників та ролями (*Власник*, *Учасник*).

### 4. 🏷️ Категорії та типи задач (Task Types)
- Кольорове кодування задач за сферами діяльності (*Робота*, *Навчання*, *Спорт*, *Особисте*).
- Менеджер типів задач: створення власних категорій з індивідуальною кольоровою палітрою.

### 5. 📱 Мобільна оптимізація та естетика
- **Сучасна дизайн-система** на Tailwind CSS (чиста світла тема та глибока темна тема з перемиканням в один клік).
- **Мобільний Drawer** — виїзне повноцінне меню на смартфонах без перевантаження екрана.
- **Швидке створення задач** — плаваюча кругла кнопка `+` для мобільних пристроїв.
- **Інтерактивний Landing** — презентація продукту з живим демо-перемикачем режимів «Канбан / Календар», списком переваг та FAQ.

## 🛠️ Технологічний стек

### Frontend
- **React 19** — інтерфейс користувача та компонентна архітектура
- **React Router 7** — клієнтська маршрутизація та захищені роути
- **Tailwind CSS** — утилітарна дизайн-система, темна тема, анімації
- **@dnd-kit/core** — сенсорний та мишачий Drag & Drop для задач
- **React Hook Form + Yup** — валідація та обробка форм
- **Axios** — HTTP-клієнт з перехоплювачами токенів та автооновленням сесії

### Backend
- **Node.js + Express 5** — REST API сервер
- **Sequelize 6 (ORM)** — об'єктно-реляційне відображення для PostgreSQL
- **PostgreSQL 16** — реляційна база даних
- **JWT (JSON Web Tokens)** — безпечна автентифікація через Access + Refresh токени
- **bcryptjs** — криптографічне хешування паролів
- **Swagger UI** — інтерактивна API документація (`/api-docs`)

### Інфраструктура та утиліти
- **Docker Compose** — локальний запуск усієї екосистеми (frontend, backend, postgres)
- **clean_comments.js** — скрипт автоматичного очищення коментарів на базі `@babel/parser`

## 🚀 Локальний запуск

### Варіант 1: Через Docker Compose (Рекомендовано)

Запуск усіх сервісів однією командою:

```bash
docker compose up --build
```

Після запуску доступні:
- **Frontend:** [http://localhost:3000](http://localhost:3000)
- **Backend API:** [http://localhost:5000/api](http://localhost:5000/api)
- **Swagger Docs:** [http://localhost:5000/api-docs](http://localhost:5000/api-docs)
- **PostgreSQL:** `localhost:5432` (БД: `task_manager`, користувач: `postgres`, пароль: `password`)

---

### Варіант 2: Запуск без Docker

#### Передумови:
- Node.js 18+
- PostgreSQL 14+

#### 1. Налаштування бази даних
Створіть базу даних `task_manager` у вашому локальному PostgreSQL:
```sql
CREATE DATABASE task_manager;
```

#### 2. Запуск Backend
```bash
cd backend
npm install
npm run dev
```

Конфігурація `backend/.env`:
```env
PORT=5000
DB_NAME=task_manager
DB_USER=postgres
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432
JWT_ACCESS_SECRET=your_super_secret_access_key
JWT_REFRESH_SECRET=your_super_secret_refresh_key
CLIENT_URL=http://localhost:3000
```

#### 3. Запуск Frontend
```bash
cd frontend
npm install
npm start
```

Конфігурація `frontend/.env`:
```env
REACT_APP_API_URL=http://localhost:5000/api
```

## 📡 Огляд API

| Метод | Ендпоінт | Опис | Доступ |
|:---|:---|:---|:---|
| **POST** | `/api/auth/register` | Реєстрація нового облікового запису | Публічний |
| **POST** | `/api/auth/login` | Вхід та отримання токенів | Публічний |
| **POST** | `/api/auth/logout` | Вихід та очищення Refresh токена | Публічний |
| **POST** | `/api/auth/refresh` | Оновлення пари токенів | Публічний |
| **GET** | `/api/tasks` | Отримання задач користувача | Авторизований |
| **POST** | `/api/tasks` | Створення нової задачі | Авторизований |
| **PUT** | `/api/tasks/:id` | Редагування задачі | Авторизований |
| **DELETE** | `/api/tasks/:id` | Видалення задачі | Авторизований |
| **PATCH** | `/api/tasks/:id/column` | Переміщення задачі в іншу колонку | Авторизований |
| **PATCH** | `/api/tasks/:id/schedule` | Призначення дати/часу (календар) | Авторизований |
| **PATCH** | `/api/tasks/:id/unschedule` | Скидання дати/часу (повернення в беклог) | Авторизований |
| **GET** | `/api/columns` | Отримання списку колонок дошки | Авторизований |
| **POST** | `/api/columns` | Створення нової колонки | Авторизований |
| **DELETE** | `/api/columns/:id` | Видалення колонки | Авторизований |
| **GET** | `/api/teams/my` | Отримання команд поточного користувача | Авторизований |
| **POST** | `/api/teams` | Створення команди (генерує код) | Авторизований |
| **POST** | `/api/teams/join` | Приєднання до команди за кодом | Авторизований |
| **POST** | `/api/teams/:id/members` | Додавання учасника за email / username | Авторизований |
| **DELETE** | `/api/teams/:id/members/:userId` | Видалення учасника / вихід з команди | Авторизований |
| **GET** | `/api/task-types` | Отримання категорій задач | Авторизований |
| **POST** | `/api/task-types` | Створення нової категорії з кольором | Авторизований |
| **DELETE** | `/api/task-types/:id` | Видалення категорії | Авторизований |
| **GET** | `/api/users` | Список колег (тільки учасники своєї команди) | Авторизований |
| **GET** | `/api/users/me` | Дані поточного профілю | Авторизований |

## 🧹 Утиліта очищення коментарів

У корені проєкту реалізовано скрипт `clean_comments.js`, який дозволяє в один клік автоматично видалити всі коментарі з вихідного коду (JavaScript, JSX, CSS) перед захистом або здачею курсової роботи:

```bash
node clean_comments.js
```
